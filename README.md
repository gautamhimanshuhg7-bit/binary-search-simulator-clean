# Binary Search Simulator

A self-contained interactive Binary Search teaching simulator.

## Live site

https://gautamhimanshuhg7-bit.github.io/binary-search-simulator-clean/

## Run locally

Open `index.html` in a modern browser. No build step, package manager, external library, or API key is required.

## Features

- Clickable pseudocode statements
- Step-by-step execution trace
- Previous, Play, Next, and Reset
- Adjustable playback speed
- Custom sorted integer arrays and target values
- Input validation
- Found, not-found, empty-array, and duplicate-value cases
- Keyboard shortcuts: Left/Right arrows, Space, and Home
- Responsive layout

## Enable GitHub Pages

1. Open Settings → Pages in this repository.
2. Set Source to **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save and wait for the first deployment.

The website requires an internet connection only to download the GitHub Pages-hosted HTML file. The simulator itself makes no external requests.
